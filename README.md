# Анимации по начертательной геометрии и инженерной графике

Сайт: https://flxshhh.github.io/animationgrafika/ (после включения GitHub Pages: Settings → Pages → `master` / root).

- Главная показывает папки лекций, внутри лекции лежат темы, тема открывает страницу с анимацией и шагами построения.
- Поиск (клавиша `/`) ищет сразу по всем лекциям.
- Анимации лежат в `anim/`, список лекций и тем задаётся массивом `LECTURES` в `index.html`.
