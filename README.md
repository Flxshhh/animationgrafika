# Анимации по начертательной геометрии и инженерной графике

Откройте `index.html` — каталог с поиском (клавиша `/`) и фильтром по разделам.
Сами анимации лежат в `anim/`. Для работы нужен интернет (three.js грузится с CDN).

Чтобы сайт открывался по ссылке: Settings → Pages → Deploy from a branch → `master` / root.
