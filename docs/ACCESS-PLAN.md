# План: закрытый доступ по ключам (вариант 2)

Статус: **отложено**. Делаем, когда сайт будет наполнен всеми лекциями.

## Что хотим
- Доступ к сайту только у людей, которым автор выдал ключ.
- Один ключ = одно устройство: ключ нельзя передать другому человеку.
- Админка: выпустить / отозвать ключ, сбросить привязку при смене телефона.
- Водяной знак с номером ключа поверх 3D-моделей (чтобы утечку было видно).

## Важные ограничения (уже обсудили)
- Настоящий HWID в браузере недоступен. Привязка к устройству — через **passkey (WebAuthn)**:
  ключ создаётся в защищённом чипе устройства, подтверждение отпечатком / Face ID.
- Запасной вариант для старых устройств — отпечаток браузера (слабее).
- Записать экран после входа можно всегда — поэтому водяной знак.
- Passkey на iPhone синхронизируется через iCloud того же владельца — это допустимо.

## Схема
1. Репозиторий `Flxshhh/animationgrafika` → **приватный** (GitHub Pages перестанет работать — так и нужно).
2. Хостинг: **Cloudflare Pages + Pages Functions**, база ключей — **Cloudflare D1** (бесплатный тариф).
3. Поток: ввод ключа → первая активация создаёт passkey и привязывает ключ →
   сервер выдаёт подписанную сессию (cookie) → только с ней отдаются `index.html` и `anim/*`.
4. Вход с тем же ключом с другого устройства → отказ «Ключ привязан к другому устройству».
5. Желательно свой домен до запуска: passkey привязан к адресу сайта, менять его потом нельзя без перепривязки всех ключей.
